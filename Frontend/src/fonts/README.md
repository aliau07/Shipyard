# Fonts

Self-hosted so the app never contacts a third-party font server.

| File | Font | Weights | Source | Licence |
|---|---|---|---|---|
| `public-sans-latin-variable.woff2` | Public Sans (body text) | 100–900, variable | `@fontsource-variable/public-sans` 5.3.0 | SIL OFL 1.1 (`OFL-public-sans.txt`) |
| `source-serif-4-latin-variable.woff2` | Source Serif 4 (page and section headings) | 200–900, variable | `@fontsource-variable/source-serif-4` 5.3.0 | SIL OFL 1.1 (`OFL-source-serif-4.txt`) |

Both files are the Latin subset, which covers accented names such as Tomás and the arrows used in dependency paths are drawn from the system font.
